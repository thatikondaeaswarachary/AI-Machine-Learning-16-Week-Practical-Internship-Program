## 🎯 Learning Objectives
By the end of this week, students will master fundamental Computer Vision and CNN principles:
- **Image Preprocessing & Resizing:** Handling multi-channel RGB/Grayscale images, spatial aspect ratios.
- **Normalization:** Scaling pixel values from $[0, 255]$ to $[0, 1]$ or $[-1, 1]$.
- **Convolution Operations:** Mathematical kernels/filters, feature maps, strides, and padding.
- **Pooling Mechanisms:** Max Pooling and Average Pooling for spatial downsampling and translation invariance.
- **CNN Architecture Design:** Stacking convolution + activation + pooling blocks followed by dense classification heads.
- **Image Classification:** Categorizing images into distinct classes with Softmax probabilities.
