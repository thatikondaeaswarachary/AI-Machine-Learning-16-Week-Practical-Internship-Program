# 16-Week AI & Machine Learning Practical Curriculum
### Next Gen Software Hub Pvt. Ltd.

**Target Audience:** Engineering Students, Aspiring Data Scientists, and AI Enthusiasts  
**Format:** Practical Hands-on, Code-First, Weekly Deliverables  
**Total Duration:** 16 Weeks (4 Months)  

---

## Program Matrix Overview (5 Phases)

| Phase | Weeks | Focus Area | Capstone Checkpoint |
| :--- | :--- | :--- | :--- |
| **Phase 1** | Week 01 – 04 | **Python & Data Fundamentals** | Clean, ML-ready Data Pipeline & 15-Question EDA |
| **Phase 2** | Week 05 – 08 | **Machine Learning** | Classification Benchmark, Regression & Segmentation |
| **Phase 3** | Week 09 – 10 | **Advanced Machine Learning** | Feature Engineering, GridSearchCV & Ensembles |
| **Phase 4** | Week 11 – 14 | **Deep Learning & Specialized AI** | ANN, CNN Image Classifier, NLP & Recommender Engine |
| **Phase 5** | Week 15 – 16 | **AI Application & Deployment** | Interactive Web UI & Portfolio-Ready Capstone Project |

---

# PHASE 1 — PYTHON & DATA FUNDAMENTALS

---

### WEEK 1 — Python Programming for AI/ML
- **Task:** Python Fundamentals
- **Learn:**
  - Variables and data types
  - Operators
  - Conditional statements
  - Loops
  - Functions
  - Lists, tuples, sets, dictionaries
  - String manipulation
  - Exception handling
  - File handling
  - Basic OOP
- **Practical Assignment:** Build a **Student Management System** using Python.
  - *Features:*
    - Add student
    - View students
    - Search student
    - Update student
    - Delete student
    - Calculate marks and grades
- **Submission:**
  - Python source code (`main.py`, `student.py`, `student_manager.py`, `storage.py`)
  - Sample data (`students_sample.json`)
  - Screenshots
  - `README.md`

---

### WEEK 2 — NumPy, Pandas & Data Visualization
- **Task:** Data Analysis Using Python
- **Learn:**
  - NumPy arrays & array operations
  - Pandas DataFrames: Filtering, sorting, grouping, aggregation
  - Matplotlib & Seaborn
- **Practical Assignment:** Choose a real-world dataset (Sales, E-Commerce, Customer, Student, Employee) and perform:
  1. Dataset loading
  2. Data exploration
  3. Data type analysis
  4. Missing-value analysis
  5. Duplicate detection
  6. Statistical analysis
  7. At least 6 visualizations
  8. Trend and pattern identification
- **Submission:**
  - Jupyter Notebook (`starter_notebook.ipynb`)
  - Dataset (`ecommerce_sales_data.csv`)
  - Visualizations
  - Analysis summary

---

### WEEK 3 — Data Cleaning & Preprocessing
- **Task:** Prepare Data for Machine Learning
- **Learn:**
  - Missing value handling
  - Duplicate removal
  - Outlier detection (IQR / Z-score)
  - Label Encoding & One-Hot Encoding
  - Feature Scaling & Normalization
  - Train-Test Split
- **Practical Assignment:** Take a raw dataset (`customer_churn_raw.csv`) and convert it into an ML-ready dataset.
  - *Document:* Data problems found, cleaning techniques, features selected, preprocessing techniques, reasons for each decision.
- **Submission:**
  - Raw dataset
  - Cleaned dataset
  - Jupyter Notebook
  - Preprocessing report

---

### WEEK 4 — Exploratory Data Analysis
- **Task:** Complete EDA Project
- **Analyze:**
  - Data distributions
  - Relationships between variables
  - Correlations
  - Outliers
  - Trends
  - Important features
- **Practical Assignment:** Create at least 15 analytical questions and answer them using data and visualizations.
- **Submission:**
  - Jupyter Notebook
  - Minimum 10 visualizations
  - Analytical questions and answers
  - EDA report

---

# PHASE 2 — MACHINE LEARNING

---

### WEEK 5 — Machine Learning Fundamentals
- **Task:** Build Your First ML Model
- **Learn:**
  - AI vs ML
  - Supervised Learning vs Unsupervised Learning
  - Features & Target variables
  - Training and testing
  - Model prediction
  - Overfitting & Underfitting
- **Practical Assignment:** Build one basic ML model for either Regression (House Price Prediction, Salary Prediction) or Classification (Student Pass/Fail, Customer Churn, Spam Detection).
- **Submission:**
  - Jupyter Notebook
  - Dataset (`experience_salary_data.csv`)
  - Trained model (`.joblib`)
  - Prediction results

---

### WEEK 6 — Classification Algorithms
- **Task:** Build & Compare Classification Models
- **Implement at least 3 algorithms:**
  - Logistic Regression
  - Decision Tree
  - K-Nearest Neighbors (KNN)
  - Random Forest
  - Support Vector Machine (SVM)
- **Evaluation:** Accuracy, Precision, Recall, F1-Score, Confusion Matrix
- **Practical Assignment:** Train multiple classification models using the same dataset (`loan_default_data.csv`) and compare their performance.
- **Submission:**
  - Notebook
  - Model comparison table
  - Evaluation results
  - Conclusion

---

### WEEK 7 — Regression Algorithms
- **Task:** Build a Regression Prediction System
- **Implement:**
  - Linear Regression
  - Multiple Linear Regression
  - Decision Tree Regression
  - Random Forest Regression
- **Evaluation Metrics:** MAE, MSE, RMSE, R² Score
- **Practical Assignment:** Build a House Price, Salary, or Sales Prediction System with residual diagnostics.
- **Submission:**
  - Notebook
  - Dataset (`housing_prices_data.csv`)
  - Predictions
  - Evaluation report
  - Model comparison

---

### WEEK 8 — Unsupervised Learning
- **Task:** Customer Segmentation Using Clustering
- **Learn:**
  - Unsupervised Learning
  - K-Means
  - Hierarchical Clustering
  - Elbow Method & Silhouette Analysis
  - Cluster visualization (PCA)
- **Practical Assignment:** Build a Customer Segmentation System.
  1. Prepare customer data (`mall_customers_segmentation.csv`).
  2. Select relevant features.
  3. Determine suitable clusters (Elbow + Silhouette).
  4. Apply clustering.
  5. Visualize clusters.
  6. Analyze each customer segment persona.
- **Submission:**
  - Jupyter Notebook
  - Cluster visualization
  - Segment analysis
  - Insights report

  - House Price Predictor
  - Student Performance Predictor
  - Spam Detector
  - Sentiment Analyzer
  - Image Classifier
  - Customer Churn / Loan Default Risk Predictor

  Users should be able to:
  1. Enter/upload input.
  2. Submit the input.
  3. Process the input.
  4. Receive a prediction.
  5. View results clearly.
  6. Receive appropriate error messages.
- **Submission:**
  - Source code (`api.py`, `streamlit_app.py`)
  - Trained model (`loan_model.joblib`)

- **Deep Learning:** TensorFlow / Keras or PyTorch

---

## GENERAL GUIDELINES
- Submit original work only.
- Do not directly copy projects from the internet.
- Mention the source of datasets and external resources.
- Keep notebooks and source code properly organized.
- Use meaningful variable and function names.
- Document important decisions and methodology.
- Maintain projects on GitHub.
- Test models before final submission.
- Students should be able to explain their code, model, evaluation metrics, and results.
