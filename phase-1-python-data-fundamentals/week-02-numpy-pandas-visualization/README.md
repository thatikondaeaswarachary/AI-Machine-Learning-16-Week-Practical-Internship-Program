# Week 02 — NumPy, Pandas & Data Visualization
**Next Gen Software Hub Pvt. Ltd. — AI & ML Internship Program**

---

## 🎯 Learning Objectives
1. Perform high-speed numerical computations and vectorized transformations using **NumPy**.
2. Master tabular data manipulation with **Pandas** DataFrames (indexing, filtering, grouping, aggregation).
3. Generate publication-quality static and statistical graphics with **Matplotlib** and **Seaborn**.
4. Identify real-world patterns, customer trends, and distribution anomalies from raw business data.

---

## 📚 Topics Covered
- **NumPy ndarrays:** Creation, shapes, broadcasting, math functions, linear algebra basics.
- **Pandas DataFrames:** Reading CSV/JSON, `.loc` & `.iloc`, boolean indexing, `.query()`.
- **Data Aggregation:** `.groupby()`, `.agg()`, pivot tables, crosstabs, sorting.
- **Visualization:**
  - Matplotlib: Figure/Axes hierarchy, subplots, line plots, bar charts, custom legends.
  - Seaborn: Histograms (`histplot`), KDEs, Box plots (`boxplot`), Heatmaps (`heatmap`), Scatter plots (`scatterplot`).

## 🛠️ Practical Assignment: E-Commerce Data Analytics
Analyze the provided `datasets/ecommerce_sales_data.csv` dataset and produce an exhaustive Exploratory Analysis report.

### Required Steps:
1. **Dataset Ingestion:** Load data, inspect dimensions, memory footprint, and column types.
2. **Exploration & Quality Audit:** Check for null values, inconsistent types, and duplicate rows.
3. **Statistical Profiling:** Compute mean, median, IQR, variance, and skewness of revenue and sales volume.
4. **Groupby Aggregations:** Analyze revenue performance across product categories and regions.
5. **Six Distinct Visualizations:**
   - Visual 1: Distribution of Purchase Amount (Histogram + KDE).
   - Visual 2: Monthly Sales Revenue Trend (Line plot).
   - Visual 3: Total Sales by Product Category (Bar plot).
   - Visual 4: Payment Method vs Total Spending (Box plot / Violin plot).
   - Visual 5: Correlation Heatmap between numerical variables.
   - Visual 6: Age vs Spending colored by Gender (Scatter plot).
6. **Executive Insights:** Formulate 5 actionable business recommendations based on your findings.
