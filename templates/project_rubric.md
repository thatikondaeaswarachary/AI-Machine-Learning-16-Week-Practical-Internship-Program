# Evaluation Rubric & Grading Standard
**Next Gen Software Hub Pvt. Ltd. — AI & ML Internship Program**

Every weekly assignment and the final capstone project are assessed against a standardized 100-point rubric.

---

## Weekly Assignment Scoring Matrix (100 Points Total)

| Category | Max Points | Exemplary (90-100%) | Proficient (75-89%) | Developing (50-74%) | Unsatisfactory (<50%) |
| :--- | :---: | :--- | :--- | :--- | :--- |
| **1. Functional Correctness & Completeness** | **35** | All required features/tasks are fully implemented, execute error-free, and edge cases are handled gracefully. | Core features work as specified. Minor edge cases produce unhandled warnings. | Partial implementation; some core features are broken or missing. | Code does not run or critical logic is incomplete. |
| **2. Code Architecture & Engineering Standards** | **20** | Clean OOP / modular structure, PEP 8 compliance, clear variable naming, type hints, informative comments. | Organized code with minor stylistic deviations. Basic error handling included. | Monolithic code structure, lack of modular functions, sparse comments. | Hardcoded values, poor variable naming, no comments or error handling. |
| **3. Analytical Depth & Scientific Rigor** | **25** | Deep statistical reasoning, insightful interpretation of metrics, justifiable preprocessing & modeling choices. | Sound metrics and techniques selected with reasonable explanations. | Superficial analysis; numbers/plots presented without adequate interpretation. | Incorrect choice of metrics or flawed statistical assumptions. |
| **4. Visualization & Communication** | **20** | Publication-grade plots (labels, titles, legends, harmonious colors) and polished markdown documentation. | Clear plots and structured documentation covering all main questions. | Basic default plots lacking titles/labels; hurried documentation. | No visualizations or unreadable presentation. |

---

## Capstone Project Evaluation Matrix (Week 16)

The Capstone Project carries a total weight of **200 Points** across five dimensions:

1. **Problem Formulation & Domain Impact (30 Points):** Real-world significance, scope clarity, and dataset suitability.
2. **Data Pipeline & Feature Engineering (40 Points):** Automated cleaning, validation, leak-free preprocessing, expressive features.
3. **Modeling Rigor & Benchmark Comparison (50 Points):** Baseline vs advanced models, ablation study, hyperparameter tuning, metric trade-offs.
4. **Production Deployment & Architecture (50 Points):** Working FastAPI backend, Streamlit/React frontend, containerization, latency/performance consideration.
5. **Technical Documentation & Defense Presentation (30 Points):** Comprehensive repository README, architecture diagrams, live demo, and oral defense.

---

## Grading Thresholds
- **Distinction (90% - 100%):** Demonstrates junior/mid-level industry engineering readiness.
- **Pass (75% - 89%):** Successfully meets all practical internship competency standards.
- **Needs Revision (< 75%):** Must refactor and resubmit within 5 business days for re-evaluation.
